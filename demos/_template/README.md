## **🧡 학급 정서 기록 (Classroom Emotion Tracker)**

초등학교 담임교사와 학생을 위한 학급 정서 관리 도구입니다. **무드미터(감정 기록·달력)**, **오늘의 주인공(랜덤 선정)**, **칭찬샤워(긍정 메시지 누적)** 를 하나의 앱에서 운영할 수 있습니다.

2026-1학기 클라우드 프로그래밍 · 송혜윰(M20261507) 프로젝트

---

## 1. 무엇을 할 수 있나요

1. **무드미터 기록** →  16가지 감정 중 오늘의 감정을 선택하고, 달력 형태로 한 달치 감정 흐름을 시각적으로 확인
2. **오늘의 주인공 선정** → 매일 학급의 '그날의 주인공' 1명을 랜덤으로 선정(전날 뽑힌 학생 자동 제외)
3. **칭찬 샤워 기록** → 주인공에게 타이핑 또는 음성으로 칭찬 메시지 남기기, 선생님 게정으로 전체 칭찬 내역 CSV 다운로드 가능

## 3. 주요 기능 상헤

```bash

python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate

# 2) 라이브러리 설치
pip install -r requirements.txt
```

브라우저가 자동으로 `http://localhost:8501`을 엽니다. 
사이드바에서 CSV를 업로드하거나 샘플 데이터로 시작해보세요.

## 4. 주요 기능별 사용법

### 🎨 기능 1: 무드미터 기록
- 날짜와 학생 이름을 선택
- 감정 색상(빨강/파랑/노랑/초록) 선택
- 감정 단어 입력 후 저장
- → 해당 날짜의 학생별 감정 기록이 테이블로 표시되고, 감정별 색상이 시각적으로 구분

### 🎉 기능 2: 칭찬샤워 관리
- 오늘의 주인공 학생 선택
- 칭찬 내용을 텍스트로 입력 후 저장
- → 칭찬 기록이 날짜별로 목록으로 쌓이고, 학부모 알림장용 문구가 **자동으로 생성**
- 복사 버튼으로 알림장에 붙여넣기 가능

### 📊 기능 3: 학생별 성장 리포트
- 학생 이름 선택 및 조회 기간 설정
- '기록 보기' 버튼 클릭
- → 감정 변화 추이 그래프 + 칭찬 누적 현황 + 생기부 초안이 한 화면에 표시

## 6. 데이터 관리 방법

### 세션 중 기록 유지 (st.session_state)
- 앱 실행 중 모든 기록은 메모리에 저장됩니다.
- 새로고침하면 초기화됩니다.

### 기록 백업 및 이어쓰기
```python
# 수업 후 CSV로 내려받기 (다운로드 버튼 사용)
# → 다음 수업 시 사이드바에서 CSV 업로드
# → 이전 기록에서 계속 추가 기록
```

이 방식으로 "영구 저장"을 만들지 않으면서도 누적 기록을 유지할 수 있습니다.

## 8. 만들지 않은 것 (Out of Scope)

- 로그인/회원가입
- 데이터 영구 저장 (DB, 서버 파일) — *session_state + CSV 백업으로 대체*
- 외부 AI API 호출 (ChatGPT, Claude 등) — *템플릿 기반 문구 생성으로 대체*
- 이메일 발송, 알림
- 모바일 반응형 디자인 (PC 웹 브라우저 기준)

> **v2에서 추가할 수 있는 방향:**
> - SQLite를 사용한 학생별 누적 회차 저장
> - 학반 단위 감정 비교 분석
> - 학부모 PDF 리포트 자동 생성
> - 분위기별 활동 추천 (차분한 날 → 집중 활동, 행복한 날 → 협력 활동)

## 10. 작성 가이드라인

### 선생님 입장에서 쉽게 사용하기
- 타이핑 최소화: 드롭다운·버튼·라디오 버튼 활용
- 수업 중 태블릿에서도 빠르게 입력 가능한 UI
- 결과를 한눈에 — 표·그래프·요약 문구

### 학생 관점
- 친구들의 감정 변화를 자연스럽게 인식
- '그날의 주인공'이 되는 경험과 칭찬이 동기부여
- 자신의 감정을 시각적·언어적으로 표현할 수 있는 통로

### 학부모 소통
- 자동 생성된 알림장 문구로 일일 피드백 효율화
- 학생 개인별 감정 추이 그래프로 성장 과정 공유
- 생기부 초안으로 학교생활기록부 작성 시간 단축
