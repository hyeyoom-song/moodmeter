## **🧡 학급 정서 기록 (Classroom Emotion Tracker)**

초등학교 담임교사와 학생을 위한 학급 정서 관리 도구입니다. **무드미터(감정 기록·달력)**, **오늘의 주인공(랜덤 선정)**, **칭찬샤워(긍정 메시지 누적)** 를 하나의 앱에서 운영할 수 있습니다.

> 2026-1학기 클라우드 프로그래밍 · 송혜윰(M20261507) 프로젝트

🔗 **앱 바로가기** → https://moodmeter-compliment.streamlit.app/

---

## 1. 무엇을 할 수 있나요

1. **무드미터 기록** →  16가지 감정 중 오늘의 감정을 선택하고, 달력 형태로 한 달치 감정 흐름을 시각적으로 확인
2. **오늘의 주인공 선정** → 매일 학급의 '그날의 주인공' 1명을 랜덤으로 선정(전날 뽑힌 학생 자동 제외)
3. **칭찬 샤워 기록** → 주인공에게 타이핑 또는 음성으로 칭찬 메시지 남기기, 선생님 게정으로 전체 칭찬 내역 CSV 다운로드 가능

## 3. 주요 기능별 사용법

### 🎨 기능 1: 무드미터 기록
- 로그인 후 날짜를 선택하고 16가지 감정 버튼 중 하나를 클릭
- 선택한 감정의 색상·이모지·이름이 달력 칸에 표시됨
- `◀ ▶` 버튼으로 월 이동 가능
- 선생님 계정도 본인 감정을 기록할 수 있음

### 🎁 기능 2: 오늘의 주인공
- 선물 상자 🎁 화면에서 **"오늘의 주인공 확인" 버튼**을 직접 눌러야 공개
- 북소리 🥁 애니메이션(1초) 후 주인공 이름과 풍선·폭죽 효과 등장
- **학생마다 개별적으로 열어야** 본인 화면에서 주인공 이름이 보임 (한 명이 열었다고 다른 학생에게 자동 공개되지 않음)
- 전날 뽑힌 학생은 다음 날 후보에서 자동 제외

### 💌 기능 3: 칭찬샤워
- **내가 직접 선물 상자를 열어야만** 칭찬샤워 탭에서 주인공 이름이 공개되고 칭찬 작성 가능
- 텍스트 타이핑 또는 🔴 마이크 버튼으로 음성 입력 (크롬·웨일 브라우저)
- 음성 인식 결과가 입력창에 자동으로 채워지며 등록 버튼으로 저장
- 등록된 칭찬은 작성자 이름과 함께 전체 공개
- **선생님 계정**에서만 "칭찬샤워 엑셀로 다운로드 📥" 버튼이 표시됨
  
---
## 4. 데이터 관리 방식

### 세션 중 기록 유지 (st.session_state)
- 앱 실행 중 모든 기록은 메모리에 저장됩니다.
- 새로고침하거나 앱을 재시작하면 초기화됩니다.

### 칭찬샤워 백업
- 선생님 계정으로 로그인 → 칭찬샤워 탭 → "칭찬샤워 엑셀로 다운로드 📥"
- 날짜별 주인공·작성자·칭찬 내용이 CSV로 저장됩니다.
