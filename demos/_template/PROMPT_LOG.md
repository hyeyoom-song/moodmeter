# PROMPT_LOG.md


AI(GitHub Copilot · Claude)에게 입력한 프롬프트 기록. 시간 순서대로, 시행착오 포함.


> **사용한 프롬프트가 70개가 넘어서 16개로 흐름을 축약하여 정리하였습니다.**

## #1 — 프로젝트 초기 골격


> **Prompt**
> Streamlit으로 "학급정서기록" 웹앱을 만들 거야. 사용자는 초등학교 담임교사이고 파이썬 지식이 없어.
> 기능은 크게 3가지야: ① 무드미터(감정 기록·달력), ② 오늘의 주인공(랜덤 선정), ③ 오늘의 칭찬샤워(긍정 메시지 누적).
> `app.py`의 기본 골격만 만들어줘. `st.set_page_config`로 페이지 제목과 아이콘을 설정하고, 제목과 한 줄 설명을 띄워줘.


**결과:** 페이지 설정 + 제목/캡션 3줄. 기본 뼈대 완성.

## #2 — 무드미터: 감정 선택 UI


> **Prompt**
> 무드미터 페이지를 만들어보자.
> 16가지 감정과 그 감정에 맞는 색을 고르는 페이지를 만들고 싶어.
> 감정 탭은 모서리가 둥근 모양으로 4x4로 배열해줘.
> 감정을 선택하면 글씨와 색이 함께 나오도록 사각형 위에 글씨와 색을 같이 담아줘.


**결과:** 4x4 감정 버튼 그리드 완성. 단, 이모지와 글씨가 중복 표시되는 문제 발생 → #3에서 수정.

## #3 — 무드미터: 달력 구현 (시행착오)


> **Prompt**
> 학생별 감정 기록을 달력처럼 만들어줘.
> 상단에 일·월·화·수·목·금·토 순으로 되어있도록 만들고, 일요일부터 시작하는 일반 달력 모양이야.
> 상단에 몇 월인지 나타내주고, 화살표로 다른 월로 넘어갈 수 있도록 만들어줘.
> 감정을 선택하면 달력 날짜 한 칸에 감정의 색·이름·이모지가 채워지도록 해줘.


**결과:** 달력 구조는 잡혔지만 색이 테두리로만 표시되고 칸이 채워지지 않음. 오류 수정만 5회 반복.


> **교훈: "달력처럼 만들어줘"처럼 모호한 표현보다 "날짜 칸 배경색을 감정 색으로 채우고, 이모지와 이름을 칸 안에 표시"처럼 결과물을 구체적으로 묘사해야 한다.**

> EMOTIONS 리스트에서 직접 색상을 가져와서 달력 칸 배경색에 적용해줘.


**결과:** 감정 버튼 색 = 달력 배경색 완전 일치. 시각적 일관성 확보.

| **2. 말보다 '이미지'로 에러 설명하기** | 줄 바꿈이 깨지거나 달력 레이아웃이 꼬이는 복잡한 상황에서는, 백 마디 말보다 **오류 화면이나 원하는 UI 캡처본을 직접 보여줄 때** AI가 맥락을 정확히 이해하고 디버깅했습니다.[cite: 2] |
| **3. 구체적인 도메인 맥락과 수치 제약 제공** | 사용자가 초등학교 저학년이라는 특성, 예외 처리 필요한 데이터 조건, 정확한 색상 코드 등을 명확히 지정해 줄 때 실패율이 확실히 낮아집니다.[cite: 1, 2] |

### ⚠️ 나쁜 프롬프트 1순위: 감정적 대응과 주관적 표현

* **감정적으로 짜증 내거나 화내기**
  * 코드가 원점으로 돌아가거나 같은 에러가 반복될 때 감정적으로 다그치는 것은 해결에 도움이 되지 않습니다.[cite: 2] 철저하게 코드의 증상과 로그를 바탕으로 이성적으로 지시해야 최적의 코드가 나옵니다.[cite: 2]
* **주관적이고 모호하게 표현하기 (가장 조심해야 할 부분!)**
  * **"선물 상자를 크게 만들어줘", "달력을 보기 좋게 키워줘"** 같은 주관적인 표현은 절대 피해야 합니다.[cite: 2] AI는 기준을 모르기 때문에 화면을 다 덮을 정도로 비정상적으로 크게 만드는 결과를 초래합니다.[cite: 2]
  * 반드시 **"기존 크기의 3배로 키워줘"**, **"화면 너비의 1/3을 차지하게 해줘"**, 혹은 **"픽셀(px) 단위"**를 명확히 지정하여 AI가 계산할 수 있는 물리적인 기준을 주어야 합니다.[cite: 2]

> **💡 최종 결론 (Takeaway)**
> 질문은 하나씩 쪼개서 던지고,[cite: 2] 화면 에러는 시각 자료(이미지)를 적극 활용하며,[cite: 2] 크기나 간격을 조절할 때는 "크게/작게"가 아니라 **"몇 배로", "몇 픽셀(px)로"** 지정하여 주관성을 배제하자![cite: 2]
