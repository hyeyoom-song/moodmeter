AI(GitHub Copilot · Claude)에게 입력한 프롬프트 기록. 시간 순서대로, 시행착오 포함.


> **사용한 프롬프트가 70개가 넘어서 20개로 흐름을 축약하여 정리하였습니다.**

## #1 — 프로젝트 초기 골격


> **Prompt**
> Streamlit으로 "학급정서기록" 웹앱을 만들 거야. 사용자는 초등학교 담임교사이고 파이썬 지식이 없어.
> 기능은 크게 3가지야: ① 무드미터(감정 기록·달력), ② 오늘의 주인공(랜덤 선정), ③ 오늘의 칭찬샤워(긍정 메시지 누적).
> `app.py`의 기본 골격만 만들어줘. `st.set_page_config`로 페이지 제목과 아이콘을 설정하고, 제목과 한 줄 설명을 띄워줘.


**결과:** 페이지 설정 + 제목/캡션 3줄. 기본 뼈대 완성.

## #2 — 무드미터: 감정 선택 UI


> **Prompt**
> 무드미터 페이지를 만들어보자.
> 16가지 감정과 그 감정에 맞는 색을 고르는 페이지를 만들고 싶어.
> 감정 탭은 모서리가 둥근 모양으로 4x4로 배열해줘.
> 감정을 선택하면 글씨와 색이 함께 나오도록 사각형 위에 글씨와 색을 같이 담아줘.


**결과:** 4x4 감정 버튼 그리드 완성. 단, 이모지와 글씨가 중복 표시되는 문제 발생 → #3에서 수정.

## #3 — 무드미터: 달력 구현 (시행착오)


> **Prompt**
> 학생별 감정 기록을 달력처럼 만들어줘.
> 상단에 일·월·화·수·목·금·토 순으로 되어있도록 만들고, 일요일부터 시작하는 일반 달력 모양이야.
> 상단에 몇 월인지 나타내주고, 화살표로 다른 월로 넘어갈 수 있도록 만들어줘.
> 감정을 선택하면 달력 날짜 한 칸에 감정의 색·이름·이모지가 채워지도록 해줘.


**결과:** 달력 구조는 잡혔지만 색이 테두리로만 표시되고 칸이 채워지지 않음. 오류 수정만 5회 반복.


> **교훈: "달력처럼 만들어줘"처럼 모호한 표현보다 "날짜 칸 배경색을 감정 색으로 채우고, 이모지와 이름을 칸 안에 표시"처럼 결과물을 구체적으로 묘사해야 한다.**

**결과:** 감정 버튼 색 = 달력 배경색 완전 일치. 시각적 일관성 확보.

## #12 — 오늘의 칭찬샤워: 음성→텍스트 반영 문제 해결


> **Prompt**
> 음성인식 결과를 Streamlit의 st.text_area에 자동으로 넣는 방법을 찾아줘.
> JS가 window.parent.document.querySelectorAll('textarea')로 Streamlit의 textarea DOM을 직접 찾아서
> nativeInputValueSetter와 input 이벤트로 React 상태까지 업데이트하는 방식으로 작성해줘.
> placeholder 텍스트로 올바른 textarea를 찾도록 해줘.


**결과:** 음성인식 결과가 Streamlit textarea에 실시간 반영됨. 등록 버튼도 정상 작동.

## #17 — st.session_state 위젯 초기화 오류 해결


> **Prompt**
> 등록 버튼을 눌렀을 때 `st.session_state.praise_input = ""`으로 입력창을 초기화하면
> StreamlitAPIException이 떠.
> 이 한 줄을 삭제하면 되는 거야? st.rerun()이 실행되면 자동으로 초기화되나?


**결과:** 해당 줄 삭제로 해결. `st.rerun()` 실행 시 위젯이 자동으로 초기화됨을 확인.


> **교훈: Streamlit에서는 렌더링된 위젯의 session_state 값을 코드로 직접 바꾸는 게 금지되어 있다. st.rerun()으로 페이지를 새로 그리면 자동 초기화된다.**

## 🪜 회고: 잘 된 프롬프트의 공통점


| 좋은 프롬프트의 특징 | 사례 |
|---|---|
| **단계를 순서대로 번호로 설명** | 선물 상자 확인 흐름을 1·2·3·4로 명시 (#8) |
